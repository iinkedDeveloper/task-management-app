Task Management Application
Overview

A full-stack task management application that allows users to create, view, and delete tasks through a responsive web interface. The application uses JavaScript on the front end and Node.js with Express on the back end to manage task data.

Features
Create tasks
View tasks
Delete tasks
Responsive interface
Dynamic task rendering
REST API communication
