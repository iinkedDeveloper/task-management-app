# Task Management Application

## Overview

A full-stack task management application that allows users to create, view, and delete tasks through a responsive web interface. The application uses JavaScript on the front end and Node.js with Express.js on the back end to manage task data.

## Features

- Create tasks
- View tasks
- Delete tasks
- Responsive user interface
- Dynamic task rendering
- REST API communication

## Technologies Used

### Front End
- HTML5
- CSS3
- JavaScript

### Back End
- Node.js
- Express.js

### Other
- Fetch API
- JSON
- REST API

## Skills Demonstrated

- CRUD Operations
- DOM Manipulation
- Event Handling
- Async/Await
- Responsive Web Design
- API Development

## Installation

1. Clone the repository:

```bash
git clone https://github.com/iinkeddeveloper/task-management-app.git
```

2. Navigate to the project:

```bash
cd task-management-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```
